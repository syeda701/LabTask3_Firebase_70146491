BEFORE RUNNING:
1. Create your own Firebase project + Realtime Database (test mode).
2. Register the app with package name com.example.uollostfound.
3. Download google-services.json and put it in the app/ folder
   (app/google-services.json). It is NOT included here on purpose.
4. Open this folder in Android Studio, sync Gradle, run.
Note: if Gradle sync complains about the wrapper, let Android Studio
update it, or copy the src folder into a new Empty Views Activity project
with the same package name.
